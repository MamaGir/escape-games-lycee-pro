# Points à vérifier — Les fiches du four

Le contenu reprend fidèlement le chapitre « Les pâtes céramiques » (CAP 1, version simplifiée) de l'enseignant. Les chiffres ci-dessous varient selon les sources et les fournisseurs : ils sont ceux du cours, à confirmer si vous changez de référence.

| Point | Valeur dans le jeu | Énigmes |
|---|---|---|
| Températures de cuisson | terre cuite et raku 1000 °C, faïence 1050 °C, grès et vitreous 1280 °C, porcelaine 1280 à 1400 °C | 5-1, 5-2, 5-3, leçon 5 |
| Terre à feu | résiste à environ 1500 °C | 3-1, 3-4 |
| Bentonite classée parmi les argiles secondaires | phrase du cours « les argiles suivantes sont des argiles secondaires » | non évalué directement |
| Recettes | porcelaine 25/25/25/25 ; grès 50/30/10/5/5 ; raku 55/25/20 | 5-4, évaluations |
| Ordre 5-1 | la porcelaine dure (1400 °C) est placée après le grès (1280 °C) ; la porcelaine tendre (1280 °C) n'est pas dans la liste pour éviter une égalité | 5-1 |

## Photos

- **Photos du cours** : leur licence n'est pas connue. Le dépôt GitHub étant public, ne les poussez qu'après avoir vérifié qu'elles sont libres de droits (ou gardez la planche hors du dépôt).
- **Photos libres** : `python scripts/images.py commons "kaolin quarry" -n 5` (puis « ball clay », « fire clay », « stoneware clay », « red clay quarry », « bentonite »), vérifier la licence, puis `outils/photos/deposer-photos.py --dossier … --credits "…"`.
