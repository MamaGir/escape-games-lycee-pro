# Médias — Les fiches du four (tous facultatifs)

Le jeu fonctionne sans aucun fichier : décors et personnages sont dessinés en SVG.

| Dossier | Noms attendus | Rôle |
|---|---|---|
| `images/decors/` ou `videos/` | `salle1` … `salle5`, `intro`, `final` (.jpg / .mp4) | remplacent les décors dessinés |
| `images/personnages/` | `maelle`, `ines`, `theo`, `awa`, `lucas`, `ferrand` (.png) | remplacent les portraits dessinés |
| `images/documents/` | `gisements-argiles.jpg` | planche de la leçon 3 (`outils/photos/deposer-photos.py`) |
| `images/cartes/` | `<base>.jpg` (champ `media` d'une énigme) | illustration d'une énigme |

Créditer chaque fichier dans `medias/CREDITS-medias.md`. Aucune personne réelle ; schémas jamais générés par IA.
