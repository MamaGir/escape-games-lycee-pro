# Points à vérifier — Panne à l'usine

Le contenu reprend le cours « La préparation des pâtes céramiques » (CAP, V9) de l'enseignant. Aucun chiffre n'est inventé. Points à confirmer :

| Point | Valeur dans le jeu | Énigmes |
|---|---|---|
| Température de l'air chaud de l'atomiseur | « environ 400 °C » (écrit dans le cours) | 3-1, 4-2, leçon 4 |
| Consignes de sécurité avec les poudres | le cours dit seulement que les poudres sont « fines et volatiles » ; les gestes (masque anti-poussières, ouvrir les sacs avec précaution, éviter de respirer la poudre, ne pas souffler sur la poudre renversée) sont du bon sens ajouté pour le jeu : à ajouter au cours ou à valider | 5-3 |
| Nombre d'étapes | pâtes plastiques 8, barbotine de coulage 6, poudres atomisées 10, voie sèche 5 (cours, tableau des trois procédés) | 2-4, 3-3, 4-2, 5-4 |
| Étape 5 « délayage » | placée avant le transfert, comme dans le tableau du cours | 2-1, 3-3, 4-2 |
| Usine fictive « Terres et Feux » | inventée ; le cours précise que les procédés sont des exemples | introduction |
| Vidéo de l'entreprise Goicoechea (QR code du cours) | non reprise dans le jeu | — |
